 数据库初始化说明

 1. 适用范围
本说明适用于当前项目：
- 项目名称：古诗词推广系统
- 数据库类型：MySQL 8.0+
- 数据源：`yht050511/gushiwen`
当前仓库中数据库相关文件：
- `repo_data/gushiwen-yht050511/gushiwen.sql.gz`
- `poetry_full_init.sql`
2. 初始化目标
初始化完成后，本地将具备两个数据库：
- `gushiwen_raw`
  - 原始数据导入库
  - 主要包含原始表：`shiwen`
- `poetry_clean`
  - 项目业务数据库
  - 包含诗词内容、作者、句子、相关推荐、每日推荐、用户、学习、社区等表
3. 初始化流程
第一步：进入项目根目录
```powershell
cd 项目根目录
```
 第二步：解压原始数据文件
需要把：
- `repo_data/gushiwen-yht050511/gushiwen.sql.gz`
解压为：
- `repo_data/gushiwen-yht050511/gushiwen.sql`
如果你已经解压过，可以跳过这一步。 第三步：创建原始数据库
```powershell
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS gushiwen_raw DEFAULT CHARACTER SET utf8mb4 DEFAULT COLLATE utf8mb4_unicode_ci;"
``
说明：
- `root` 可以替换成你自己的 MySQL 用户名
- 执行后会提示输入密码
 第四步：导入原始数据
```powershell
cmd /c "mysql --default-character-set=utf8mb4 -u root -p gushiwen_raw < repo_data\gushiwen-yht050511\gushiwen.sql"
```
导入成功后，原始库中应存在：
- `gushiwen_raw.shiwen`
 第五步：执行项目完整初始化脚本
```powershell
cmd /c "mysql --default-character-set=utf8mb4 -u root -p < poetry_full_init.sql"
```
这个脚本会自动完成以下内容：
1. 清洗 `gushiwen_raw.shiwen`
2. 生成 `poetry_clean` 内容表
3. 生成句子表
4. 生成相关推荐
5. 生成每日推荐
6. 补齐团队开发所需业务表

 6. 初始化完成后的验证
进入 MySQL 后执行：
```sql
SHOW DATABASES;
USE poetry_clean;
SHOW TABLES;
``
你应该至少能看到这些表或视图：
- `author`
- `poetry_work`
- `work_sentence`
- `work_relation`
- `daily_recommendation`
- `daily_recommend_item`
- `app_user`
- `study_plan`
- `quiz_record`
- `community_post`
- `community_comment`
- `v_api_daily_recommend`
- `v_api_related_work`

建议继续检查数据量：
```sql
USE poetry_clean;
SELECT COUNT(*) AS author_count FROM author;
SELECT COUNT(*) AS work_count FROM poetry_work;
SELECT COUNT(*) AS sentence_count FROM work_sentence;
SELECT COUNT(*) AS relation_count FROM work_relation;
SELECT COUNT(*) AS daily_count FROM daily_recommendation;
SELECT COUNT(*) AS daily_item_count FROM daily_recommend_item;
```

4. 开发过程是否允许修改数据库

允许，但请遵守规则：

- 可以新增表、字段、索引
- 不建议随意删除已有字段和表
- 结构修改请通过新增 SQL 迁移脚本完成
- 修改后要提交到 GitHub，并同步给队友
